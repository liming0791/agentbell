# ADR 0002：文件系统持久队列

- 状态：Accepted
- 日期：2026-07-23

## 决策

M0.5 使用同一文件系统内的临时写入和原子移动实现 spool 队列，不引入数据库或 CGO。

队列包含 `pending`、`inflight`、`history`、`dead`、`tmp` 和 `keys`。`keys` 保存幂等键
占位，避免并发 Hook 对同一事件重复入队。

## 不变量

- `emit` 只有在事件文件刷新并进入 `pending` 后才报告成功；
- 原始 Hook 输入默认不持久化；
- Service claim 后崩溃时，租约到期可恢复；
- 达到最大重试次数的事件进入 `dead`，不会静默删除；
- 状态迁移先写目标状态，再删除来源，重启时可以对重复副本进行修复。

## 复审条件

如果后续 Windows 实测无法满足并发安全、崩溃恢复或 p95 200ms 门槛，必须重新评估
存储实现；M0.5 已记录的 Windows x64 验收结果满足这些门槛。
