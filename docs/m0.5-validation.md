## 发布边界

- Core、bootstrap 和 Codex Adapter 实现状态为 Technical Preview；
- 所有 catalog Adapter 当前保持 `pilot`，真实产品最低/最新版和各平台实机矩阵完成前不得
  标记为 `verified`；
- `signatureStatus=technical-preview` 是机器可读发布门禁；签名 job 尚未实现；
- M0.5 不包含系统登录自启动、真实飞书账号调用或其余 Agent 的正式 Adapter。

## 外部平台限制

- 私有仓库的 `main` 分支保护需要 GitHub Pro；2026-07-23 API 配置返回 403。CI 会自动
  运行，但 GitHub Free 无法把这些检查设为强制合并门禁。
- 本机没有 npm 登录会话，`@agentbell` scope 所有权和 Trusted Publisher 尚未确认。
  仓库变量 `NPM_PUBLISH_ENABLED=false`，因此 RC 会发布 Core 和验证后的 npm tgz，不会
  发起未经授权的 registry publish。完成 npm 账号配置后再显式开启。
- GitHub Artifact Attestation API 不支持个人账号下的私有仓库。`v0.2.0-rc.1` 的
  Release run 因该平台限制失败且标签保留不改写；仓库变量
  `AGENTBELL_ATTESTATIONS_ENABLED=false`。`v0.2.0-rc.2` 以 checksum、release
  manifest 和 Actions artifact 作为可验证发布证据。
